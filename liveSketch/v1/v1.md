# V1

Contém uma estrutura **cliente-servidor-cliente** que permite a troca de mensagens entre dois usuários. 

O servidor hospedado em `localhost` abre uma conexão na porta `6666`, que espera conexão de 2 clientes por *loopback*. Estabelecida a conexão via *Three-Way Handshake*, o servidor inicia duas threads com o mesmo objetivo: repassar mensagens de um cliente para o outro, tal qual um chat simples.

Se um dos clientes encerrar sua conexão, todas conexões também são encerradas.
