# V0

Contém uma estrutura simples **servidor-cliente** que apenas apresenta o funcionamento básico de um *socket*. 

O servidor hospedado em `localhost` abre uma conexão na porta `6666`, que logo é respondida pelo cliente por *loopback*. Estabelecida a conexão via *Three-Way Handshake*, o servidor recebe uma mensagem do cliente e retorna uma mensagem de resposta. 

A conexão é encerrada.
