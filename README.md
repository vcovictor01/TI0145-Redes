# TI0145-Redes

---

Como executar: 
<ol>
    <il>Definir o SERVER_IP em client2.py da past v2 como sendo o IP da rede local - descobrir via `ifconfig`;
    <il>Executar o arquivo server2.py da pasta v2;
    <il>Executar o arquivo client2.py na máquina desejada como actor;
    <il>Executar novamente o arquivo client2.py na máquina desejada com observer;
</ol>

Importante: Encerrar qualquer cliente encerra todo o servidor.
